## 3. 判明している注意点
- `musicList` の公開が「09-08に始まって今後増える」のか「古い回から消える」のかは**未確認**。念のため週1回程度 `fetch` して `data/episodes.json` に溜めておく
- Spotify `GET /me` の `product` は Dev Mode で取得不可。以降は `id` / `display_name` を使う
- Spotify 検索の limit は最大10。`/playlists/{id}/tracks` は `/items`。audio-features 等は使わない
- Spotify の refresh_token は約6ヶ月で失効。切れたら `data/spotify_token.json` を削除して `node scripts/auth_check.js` で再認証
- Spotify Dev Mode は Premium 必須・ユーザー5人まで（個人利用なので支障なし）
- 空の `musicList`（未放送回）は次回 fetch で更新される。2026-09-07 回だけ再放送経由（`detailedComingEvent`）で選曲が付くが、使わない
- Work_Report に Spotify ユーザーIDが載っている。リポジトリを public にする場合は先に伏せる
- PowerShell 5.1 では `&&` が使えない。コマンドは1行ずつ実行する
