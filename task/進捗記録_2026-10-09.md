- 対象: テーマ曲（NEW POINT / 西岡大貴）20件と重複1件を除外。月別は 2026-09: 40曲 / 2026-10: 18曲
- **マッチ率 96.6%（56/58）**。誤採用（別曲）は目視で 0 件。エラー 0
- 未マッチ2件（どちらも正しい曲が候補にある）:
  - 「心配無用節 -無添加-」: Spotify は「心配無用節 - 無添加」。ハイフン前後の空白差で、コア曲名ルールが効かない
  - 「Call me tonigh」: NHK 側のタイポ（Spotify は「Call me tonight」）
- 閾値比較: 50 → 56件 / 60 → 56件 / 70 → 45件（77.6%）
- **リスク**: アーティスト点が 0 で採用された曲が 11 件（19.6%）。Spotify がアーティスト名をローマ字で返すため
  （例: クレイジーケンバンド → Crazy Ken Band）。11件とも曲は正しかったが、全て**ちょうど60点**（曲名完全一致50 + 再生時間10）。閾値を上げると全滅する
- 曲名が部分一致で採用された曲は 0 件（別曲の誤採用リスクは今回は発生せず）
- 再生時間が5秒を超えて採用された曲が1件（「You (feat. UMI)」65秒差。曲は同一）

3C の報告から、次の3点を決める。推奨は括弧内。
1. **マッチ率 96.6%・閾値 60 を許容するか** → 許容してよい（誤採用0件）。ただし閾値は上げない（上げると11件が落ちる）
2. **採点ルールを変更するか**（`src/match/**` の別タスク。仮に Task 3D とする）

   - 案3 曲名のあいまい一致（レーベンシュタイン距離など）→ **見送り推奨**（別曲の誤採用リスクが増える。NHK のタイポは件数が少ない）
